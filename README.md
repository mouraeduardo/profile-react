# Portfólio - Carlos Eduardo Moura Rodrigues

Site de portfólio profissional em React + TypeScript, com layout responsivo, modo claro/escuro, animações leves ao rolar a página e dados mockados em arquivos separados.

## Como executar

```bash
npm install
npm run dev
```

Depois acesse a URL exibida no terminal, normalmente `http://localhost:5173`.
